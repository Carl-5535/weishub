## 遗留问题 1：真实手机入站消息在进入管线前被丢弃（2026-10-25 排查中）

现象：重新扫码绑定后，手机发送「你好」无回复。证据：消息**已到达 hub**（`lastActivityAt` 与新 id 的
context token 均在对应时刻落盘），但消息环/车道/发件箱均无处理痕迹——丢弃点只可能在 owner 校验
（`credential.userId` 与消息发送者 id 不一致）或去重。已给两个丢弃点补上 stderr 日志并重启，
**再发一条消息即可在 `~/.weishub/run.log` 看到实锤**（来自/会话/群聊标志/期望 owner）。

疑点背景：本次重新扫码返回的 `ilink_user_id`（凭据 userId）与历史会话的 chatId 不一致——
iLink 对同一微信用户在不同绑定代际可能下发不同的会话 id。若日志证实 owner id 不匹配，
修复方向：owner 判定除凭据 userId 外，接受历史已验证车道（持久化 lanes）的 chatId。

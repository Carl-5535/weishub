# weishub-notify：微信主动推送

通过本机 `wx` CLI 把消息推送到用户的微信（经本地 weishub hub 的 notify API 转发）。

## 用法

```bash
# 发送文本
wx send "任务完成：构建通过，共 221 个测试"

# 发送图片（本地路径）
wx send --image /path/to/report.png

# 查看连接与登录状态
wx status
```

## 何时使用

- 长任务完成或失败时（用户已离开终端）。
- 需要用户决策/确认的关键节点。
- 后台任务产出结果、用户明确要求通知时。

不要在用户明显正在交互（刚发过消息、任务秒完）时刷屏。

## 静默降级约定

- `wx` 依赖本地 hub 已启动（`weishub` 在跑）。hub 未启动时 `wx send` 会失败
  （提示「未找到 hub 令牌」或「无法连接」）。
- 失败时**静默降级**：只重试 **至多 1 次**，仍失败则放弃推送，把内容写到
  stdout/日志即可，不要阻塞当前任务、不要循环重试。
- `wx status` 可用于先探测 hub 是否可达（可选）。
